# MySilo-Pharma releases

Installers for the MySilo-Pharma desktop app, for Windows.

To install, download `MySilo-Pharma-Setup.exe` from the
[latest release](https://github.com/safdar-manan/mysilo-pharma-releases/releases/latest)
and run it. Windows may say "Windows protected your PC": choose **More info**,
then **Run anyway**.

Once installed, the app updates itself from here.

This repository holds no source code.
